# Sistem Bayaran Yuran Pelajar

Laravel 13, PHP 8.4, Sanctum, Pest 4.

Architecture decisions live in `docs/adr/`. Read them before changing
code and follow every ADR with status `accepted`. If a task conflicts
with an ADR, stop and ask.

- Run `php artisan test` before finishing; every test must pass.
- Do not edit `bootstrap/app.php` without asking.
